# 0001. 取得範囲（bounding box）の選択

- 日付: 2026-09-29
- ステータス: 承認

## 背景

OpenSky REST API の登録ユーザー枠は 4,000 クレジット/日。1リクエストのクレジットは bbox 面積で決まる（<25平方度=1, <100=2, <400=3, それ以上=4）。範囲と取得間隔はトレードオフになる。

## 選択肢

| 範囲 | bbox | 面積 | クレジット/回 | 最短間隔（4,000/日） |
|---|---|---|---|---|
| 沖縄周辺 | 24–28N, 123–129E | 24 | 1 | 約22秒 |
| 九州〜沖縄 | 24–34N, 122–132E | 100 | 3（実測は 2） | 約65秒（実測の 2 なら約43秒） |
| 日本全域 | 24–46N, 122–146E | 528 | 4 | 約86秒 |

## 実測（第1週）

| 項目 | 値 |
|---|---|
| 取得日時（UTC） | 2026-09-28 09:17:41 / 09:17:52（JST 18:17、2回） |
| 機数（row_count） | 18 / 18 |
| 取得前後の X-Rate-Limit-Remaining | 3999 → 3998（1回目の後 → 2回目の後） |
| 実クレジット消費 | 1 / リクエスト |
| JSONL.gz サイズ | 1,270 B / 1,286 B（展開後 約8.2KB、1機あたり約70B） |
| 月間推定（5分起動×10回/起動） | 2,880 リクエスト/日（上限 4,000 の 72%）、約5.2万行/日、約110MB/月（1リクエスト1ファイル換算の上限側） |

補足（1回分の観測。判断の前提として）:

- 夕方の1時点だけの値。時間帯（深夜・早朝の便の少なさ）で変わるため、機数と月間推定は日平均ではない
- 18機のうち `on_ground=true` は0機。那覇などの地上機は見えていない可能性がある（離着陸判定の設計に影響）
- `callsign` 欠損1機、位置欠損0機。国籍は Japan 11 / United States 4 / その他3
- `api_time - last_contact` の最大は266秒。古い位置が混ざるため、重複排除・鮮度の扱いが staging で必要
- 計画書の推定（約12万行/日・約1.1GB/月）より1桁小さい。10回分を1ファイルにまとめると gzip の圧縮が効き、さらに小さくなる見込み

### 比較（2026-09-29 04:08 UTC = JST 13:08、各1回）

| 項目 | 沖縄周辺 | 九州〜沖縄 |
|---|---|---|
| 機数 | 14 | 50（うち沖縄周辺の範囲内 14） |
| 緯度帯の内訳 | — | 31–34N 28 / 28–31N 2 / 24–28N 20 |
| X-Rate-Limit-Remaining（取得後） | 3997 | 3995 |
| 実クレジット消費 | 1 | **2**（面積100平方度で 3 を想定していた） |
| JSONL.gz サイズ | 1,067 B | 2,955 B |
| `on_ground=true` | 0 | 0 |
| `api_time - last_contact` 最大 | 159秒 | 305秒 |

補足:

- クレジットは UTC 0時では戻らなかった（前日最後 3998 → 当日最初の取得後 3997）。戻るタイミング（直近24時間の積算か、別の時刻か）は未確認
- 地上機は両範囲とも0機。一方、那覇・嘉手納付近で高度 1,000m 未満の機体が3機見えた（JAL913 632m、TIGER11 610m、N64686 244m）。着陸直前までは追えるため、離着陸は `on_ground` ではなく高度の変化で判定する必要がありそう
- 九州〜沖縄にすると機数は約3.6倍で、増えた分の大半は九州（31–34N）

## 決定

沖縄周辺（24–28N, 123–129E）で開始する。Cloud Run Jobs を5分ごとに起動し、1回の起動で30秒間隔×10回取得する（2,880 クレジット/日、上限の72%）。

## 理由

- 1クレジット/回なので、30秒間隔の取得を上限内で続けられる。九州〜沖縄は2クレジット/回で、同じ頻度だと上限（4,000）を超える
- 第5週のセッション化では、点の間隔が細かいほどフライトの区切りの精度が上がる
- データ量は約110MB/月以下で、GCS の無料枠（5GB）に十分収まる
- 範囲の拡大とバックフィルを第9週の題材として残せる

## 影響・見直し条件

- 1日平均の機数がセッション化・空港別集計に足りなければ、九州〜沖縄（10分ごと×10回）に広げる
- クレジットの戻り方は未確認。直近24時間の積算なら、残り28%の余裕で再試行分を賄う
- 地上機が見えないため、離着陸は高度の変化で判定する（第6週の ADR で扱う）
- 第9週に日本全域へ広げ、パーティションの再設計とバックフィルを行う
